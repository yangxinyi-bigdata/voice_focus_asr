# Architecture

## 目标

为已知目标说话人提供实时中文转写，并允许云端声纹增强、本地目标说话人提取和不同 ASR 后端独立替换。

## 主链路

```text
麦克风采集
  -> 平台音频处理（AEC / AGC / 基础降噪 / 重采样）
  -> TargetSpeakerProcessor
  -> StreamingRecognizer
  -> TranscriptUpdate
  -> UI / 文件 / 上游应用
```

## 端口

### TargetSpeakerProcessor

输入目标声纹和连续 PCM 分片，返回聚焦后的音频分片或丢弃结果。实现可以是：

- 千问 Qwen-Audio-Realtime 的说话人增强能力。
- WeSep 等目标说话人提取模型。
- 声纹验证 + VAD 门控。
- 仅用于基线的透传处理器。

### StreamingRecognizer

接收目标音频，发布可修订的增量文本和最终文本。实现可以是：

- 千问输入音频转写事件 Adapter。
- 自建 Qwen3-ASR。
- 其他支持中文的实时 ASR。

## 安全边界

- 客户端不持有长期云服务密钥。
- 日志只记录 session ID、阶段、耗时和安全错误码，不记录原始音频、声纹或转写正文。
- 声纹样本需要明确的保存期限和删除入口。
- 对他人录音与转写必须遵守适用地区的告知和同意要求。

## 可观测性

至少记录以下不含内容的指标：

- 开始到首个增量文本的延迟。
- 说话结束到最终文本的延迟。
- 目标音频通过率和非目标音频丢弃率。
- 上游重连次数和会话失败阶段。
- 测试集上的目标说话人 CER、旁人泄漏率和重叠语音 CER。
