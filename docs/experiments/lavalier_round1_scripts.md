# 双领夹麦第一轮录音稿

配合 [录音规程](./lavalier_recording_protocol.md) 使用。A = 目标说话人（对话对象），B = 用户。

## 通用要求

- **每段都是两人同时佩戴发射器、立体声录音**，包括单说场景：不说话的一方也必须戴着麦，他的声道用来测量串音。
- 用平常聊天的语速和音量，不要播音腔，也不要刻意放慢。读错了不用重来，接着读，事后在清单里按实际读出的内容修正文本。
- 每段开头先安静 2 秒，结尾再安静 2 秒。
- 两人的稿子内容互不重复，也不与声纹稿重复：输出里出现 B 的句子，就能直接判定为泄漏。
- 稿子里刻意放了时间、数字、人名、地名和短回应（“嗯”“对”），这些是聊天中最重要、也最容易识别错的内容。

## 声纹样本

各自单独录一次，另一人保持安静。录完只取说话人自己的声道。

**A 的声纹稿**（约 25 秒）：

> 我平时周末喜欢去郊区爬山，早上六点多出门，路上买个包子和豆浆。山顶风景特别好，天气晴的时候能看到很远的水库。下山以后找个农家乐吃顿饭，一般下午四点前就能回到家，晚上再看会儿书，第二天上班也不觉得累。

**B 的声纹稿**（约 25 秒）：

> 我最近在学做饭，先从简单的番茄炒蛋和青椒肉丝开始。一开始总是盐放多了，后来买了一个小量勺，味道就稳定多了。上个星期试着炖了一锅排骨汤，炖了两个小时，骨头都酥了。下一步打算学包饺子，听说和面最难掌握。

## 交替说话

两人按顺序轮流读，上一句读完立刻接下一句，不用刻意停顿。

## 清单模板

录完后保存为 `data/lavalier/round1/manifest.tsv`（Git 忽略），`target_channel` 按实际声道填写。交替说话的文本按说话人分别合并；如有读错，按实际读出的内容修改。

```text
file	case	target_channel	noise	target_text	user_text
target_only_01.wav	target_only	left	quiet	这家店我上个月来过一次……	
user_only_01.wav	user_only	left	quiet		我觉得这里有点吵……
alternating_01.wav	alternating	left	quiet	你想喝点什么……	好啊，我不要加糖……
overlap_01.wav	overlap	left	quiet	明天早上九点半……	我昨天晚上看了一部电影……
```
